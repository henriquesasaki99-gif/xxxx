Como este portal trata o arquivo

1. Lê o arquivo sem alterar nada
O conteúdo é analisado no navegador e os conjuntos de dados são identificados automaticamente.
2. Mantém uma cópia integral
Cada FBK importado é guardado como fonte original no banco local do portal.
3. Separa histórico do sistema principal
Nenhum registro é enviado para Firebase, estoque, caixa ou PDV automaticamente.
4. Permite consolidar depois
Você pode gerar um novo FBK único com as vendas históricas, ou um pacote completo com todos os conjuntos detectados.

Regras de segurança

Duplicidades
Na consolidação, registros com o mesmo originalId, id, barcode, sku, email, username ou assinatura equivalente são tratados como duplicados.
Campos originais
O portal preserva os campos originais do registro. O exportador para relatórios Delux não cria movimentação de estoque.
Pacote completo
O arquivo completo do portal serve como arquivo-mestre de recuperação e conferência; ele não deve ser importado diretamente no sistema principal sem um importador específico.

Compatibilidade

Se um arquivo .FBK for um backup binário real do Firebird, o navegador não consegue restaurá-lo sozinho. Este portal reconhece o formato FBK/JSON usado pelo sistema Delux. Para um Firebird real, seria necessário um backend com Firebird/gbak.
